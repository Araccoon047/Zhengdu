# 争渡 Android 套壳

该目录是争渡网站的 Android WebView 套壳工程，加载：

`https://araccoon047.github.io/Zhengdu/`

## 已接入

- 系统文件选择器：照片、图片、JSON 导入文件与多文件选择。
- 数据导出：通过原生桥接保存到手机 `下载/争渡备份`。
- 通知权限与原生通知通道。
- 前台保活服务、静音音频与 CPU 唤醒锁。
- 忽略电池优化设置入口。
- 自定义桌面快捷图标：上传图片后创建固定桌面快捷方式。
- 简短的启动图标淡出动画。

## 本地构建

使用仓库根目录 `.android-build` 中的 Android 35 与 Build Tools 34：

```powershell
.\android-shell\build-local.ps1
```

APK 会输出到仓库上一级目录，文件名：

`争渡+Zhengdu1.0.apk`

## 关于自定义桌面图标

Android 标准桌面不允许普通 App 直接替换已安装应用在应用抽屉或系统设置中的全局图标。因此本项目通过固定桌面快捷方式实现：用户上传图片后，系统会询问是否把带该图标和名称的快捷方式添加到桌面。
